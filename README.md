# JournalClubAssistant

레지던트 저널클럽(최신 논문 리뷰 세미나)을 위한 AI 도우미입니다.

## 배경

현재 세미나는 레지던트 한 명이 최신 논문 한 편을 준비하고, 모두가 PDF를 함께 보며 발표를 듣는 방식입니다.
하지만 논문은 분량 제한 때문에 다음 내용이 부족한 경우가 많습니다.

- **Introduction**: 이 연구가 어떤 선행 연구 흐름에서 나왔는지 설명이 짧습니다.
- **Materials and Methods**: "previously described" 등으로 다른 논문에 미루어 생략된 부분이 있습니다.

이 프로젝트는 논문 한 편을 입력받아 부족한 맥락을 보강하고, 공부용 자료와 발표 자료를 만들어 레지던트의 이해를 돕는 것을 목표로 합니다.

## 처리 흐름

입력: 리뷰할 논문 PDF 한 편

1. **연구 흐름 정리 (Research lineage)**
   - Introduction과 인용 문헌을 바탕으로, 이 연구가 이어받은 선행 연구 테마를 찾습니다.
   - 주요 선행 연구를 시간 순서로 정리하고, 그 흐름 안에서 이 논문이 갖는 의미를 설명합니다.

2. **연구 방법 보강 (Methods supplementation)**
   - 생략되었거나 다른 논문에 기술되어 있다고 한 방법을 찾아냅니다.
   - 해당 레퍼런스를 찾아 실제 방법 내용을 가져와 보강합니다.

3. **자료 생성 (Outputs)**
   - **학습용 PDF**: (1), (2)의 보강 내용과 논문의 결과를 정리한 자료
   - **발표용 슬라이드 (PPTX)**: 세미나 발표에 바로 쓸 수 있는 슬라이드

## 폴더 구조 (예정)

```
input/     리뷰할 논문 PDF
output/    생성된 학습용 PDF와 슬라이드
docs/      설계 문서와 메모
```
