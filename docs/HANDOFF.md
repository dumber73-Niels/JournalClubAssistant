이 문서는 지금까지의 결정, 시험 결과, 남은 작업을 한곳에 모은 것이다. 설계 전체는 `docs/ROADMAP.md`가 기준이고, 이 문서는 그 요약과 "다음에 무엇을 할지"다.

## 1. 프로젝트 한 줄

치주과 저널클럽 준비 도구. 논문 한 편을 입력하면 (1) 선행연구 계보를 추적하고 (2) 방법이 생략되었거나 다른 논문에 미룬 부분을 인용 문헌에서 보강하며 (3) 영어 학습 PDF와 발표 슬라이드를 만든다. 사용자(교수)는 치주과 레지던트를 교육한다. 대상 학술지는 J Periodontol, J Clin Periodontol, Clin Oral Implants Res(모두 Wiley, 대부분 구독 + 일부 OA).

## 2. 확정된 결정 (상세는 ROADMAP.md 8절)

| 항목 | 결정 |
|---|---|
| 사용 범위 | 개인 사용. 공용 폴더, 공유 기능, 공용 서버 없음 |
| 구조 | 독립 실행 로컬 웹앱(Python + 브라우저 화면). MCP 서버는 보류. 코드 서명 안 함(uv 한 줄 설치) |
| AI 연결 | API 키(Anthropic, OpenAI, Google, OpenAI 호환). 레지던트 각자 개인 키. 구독 계정 연결 안 함 |
| 로컬 모델 | 확보 가능하면 사용: 클라우드 전용(기본) / 혼합(권장) / 로컬 전용 |
| 구독 원문 | **F/L 등급제**. CC 라이선스 원문(F)만 클라우드 AI에 전문 전송. 그 외(L)는 노트북(또는 사설망의 사용자 PC) 밖으로 절대 보내지 않음. 등급 올리기 설정 없음. 도서관 확인은 하지 않음 |
| 읽기 양식 | 모든 논문에 같은 양식. L 등급은 추출 코드/로컬 모델이 초안, 사용자가 확인한 사실·메모만 클라우드로. "먼저 답하기" 문항 3-5개, 화면은 로컬 웹페이지 |
| 산출물 언어 | 영어 단일, 발표자 노트 없음 |
| 공개 | 소속 과에서 먼저 파일럿 후 외부 공개, MIT 오픈소스 |
| 병원 밖 | 프록시 주소 설정 칸만 둠 |
| 우선 유형 | Original article → SR/MA → Narrative review |

원칙: 인용은 프로그램이 조회한 실제 ID만 쓴다(LLM이 만든 인용 금지). 모든 주장에 출처와 확인 수준([FT] 전문, [U] 사용자 확인, [A] 초록, [R] 서지)을 붙인다. 클라우드로 가는 모든 요청은 전송 게이트를 거친다.

## 3. 지금까지의 시험 (모두 `docs/ROADMAP.md` 1.3절 4항에 기록)

1. **qwen3.8-flash-next 첫 시험** (한국어 vs 영어 출력, 논문 jpis-56-189): 지어낸 참고문헌 0건. 영어 출력이 더 좋았음 → 영어 단일 결정의 근거 중 하나. n=1.
2. **gemma4:e4b 1차** (`eval/local_model_extraction/`): OA 논문 3편, 문항 10개(찾기 6, 부재 판정 4) × Methods만/전체. 전부 정답, 오탐 0, 인용문의 모든 문장이 원문에 있음.
3. **gemma4:e4b 2차**: 입력 3종(PMC XML / pdftotext / 300dpi OCR) × 문항 20개 × 2조건 = 120회. 틀린 답 0건. GB10 GPU에서 호출당 평균 약 4.6초. 한계: **변별력 부족**(같은 논문 3편 반복, 쉬운 문항). OCR에서는 "MATERIALS AND METHODS" 제목 인식 실패로 섹션 분할이 깨지는 경우가 있었음(전체 텍스트 처리가 기본 경로여야 함).

실행 방법과 정답 기준은 `eval/local_model_extraction/README.md`, `score.py`.

## 4. 라이선스 측정 결과 (아직 ROADMAP.md에 반영하지 않음)

Crossref로 측정(`eval/license_survey/grade.py`).

- **학술지 전체** (2024.10-2026.9 연구·리뷰 추정): CC 라이선스 비율 J Periodontol 52%(288편), J Clin Periodontol 68%(303편), Clin Oral Implants Res 62%(262편). 2016-2017년에는 각각 0%, 6%, 약 1%.
- **저널클럽 후보 12편**(DOI: 10.1002/JPER.24-0082, JPER.24-0178, JPER.24-0250, JPER.24-0125, 10.1111/clr.14435, clr.14235, clr.14332, clr.14389, jcpe.14206, jcpe.14188, jcpe.14178, jcpe.14174): 발표 논문 12편 중 F 8편(CC BY 4, CC BY-NC-ND 3, CC BY-NC 1), L 4편(JPER.24-0082, jcpe.14206, jcpe.14178, jcpe.14174).
- **그 참고문헌** (DOI 있는 451편): F 71편(16%), L 314편(70%), 불명 66편(15%, 규칙상 L 취급). 계보·방법 보완에 쓰는 **2018년 이전 참고문헌은 232편 중 9편(약 4%)만 CC**.
- **판정 규칙 주의**: Wiley 구독 논문에는 Crossref에 `tdm_license_1.1`(Wiley 자체 TDM 라이선스)이 붙어 있다. 이것은 클라우드 AI 업로드 허락이 아니므로 **F 근거가 아니다**. CC URL이 있고 `content-version`이 `vor`/`unspecified`인 것만 F.

**함의**: 발표 논문의 약 1/3은 L, 참고문헌은 사실상 거의 전부 L이다. 따라서 **L 경로(추출 코드 + 읽기 양식 + 로컬 모델)가 참고문헌 처리의 주 경로**이고, 로컬 모델 확보는 사실상 필수에 가깝다. 이 내용을 ROADMAP.md 1.8절 "결정 전에 측정할 것", Phase 0, 위험표에 반영하고 "L 경로는 보조"라는 표현을 고쳐야 한다(미반영).

## 5. 다음 작업 (우선순위)

1. **gemma4:e4b 3차 시험 (변별력 있는 시험)**
   - 입력: 위 12편 참고문헌 중 CC 라이선스(F) 논문에서 20편 이상을 고른다(`grade.py` 결과의 `refgrades`가 CC인 DOI). 다운로드는 PMC Open Data(S3: `https://pmc-oa-opendata.s3.amazonaws.com/PMC<id>.1/PMC<id>.1.pdf`)나 PMC E-utilities 같은 **승인된 경로만** 쓴다. 출판사 사이트 크롤링 금지.
   - 입력 형태: PDF 추출 텍스트를 기본으로 하고, 도서관 스캔본 같은 **심한 OCR 손상**(저해상도 래스터, 기울임, 얼룩)도 만들어 본다.
   - 문항 설계: 방법 정보(용량, 기간, 품종, 측정법)와 **표 안의 값**, 약어 정의가 흩어진 경우, "described elsewhere"로 넘긴 항목(=원문에 상세가 없음을 판정), 비슷해 보이는 함정이 있는 부재 문항. 표현을 바꾼 질문 포함.
   - 정답 기준은 시험 대상 모델과 **다른 모델이 원문(XML)을 읽고** 만들고, 정답 키워드가 원문 텍스트에 실제로 있는지 프로그램으로 검증한다. 시험 대상 모델에게 정답을 보여 주거나 시험 중 스크립트를 고치지 않는다.
   - 채점은 `score.py`를 확장해 쓴다(찾기 정답, 부재 정답/오탐, 인용문 일치, 입력 손상 분리).
2. **iMac(2017, macOS 13, 32GB, Intel CPU) 속도 측정**: Ollama는 macOS 14 이상 필요해 설치 불가. llama.cpp 직접 빌드 + Gemma 4 E4B 4비트 GGUF로 같은 입력의 속도만 측정. edgexpert에서 품질이 확인된 뒤에 한다.
3. **로드맵 반영**: 4절의 측정 결과와 판정 규칙, 3차 시험 결과.
4. **엔진 구현 시작**(ROADMAP.md Phase 1): 라이선스 판정 모듈, PDF 해석, 추출 코드, 전송 게이트, 개인 문헌 보관함. 첫 기준 자료는 jpis-56-189(출력물은 저장소에 없음, 이전 세션 로컬).

## 7. 작업 규칙

- 사용자에게는 **한국어**로 답한다. 산출물(학습 PDF, 슬라이드)은 영어.
- 논문 PDF, 논문 본문 텍스트, 생성 산출물, 모델 출력은 **저장소에 올리지 않는다**(`input/`, `output/`, `eval/**/*_full.txt` 등은 `.gitignore`).
- 커밋과 푸시는 사용자가 요청할 때 한다. 커밋 메시지 끝에 세션의 attribution 줄을 붙인다.
- 숫자·식별자는 프로그램으로 대조한다. 확인하지 못한 것은 확인하지 못했다고 쓴다.
- 시험은 한 번에 한 가지를 바꾼다. 결과는 `docs/ROADMAP.md` 1.3절에 같은 형식(표 + 해석 + 한계 + 다음 시험)으로 기록한다.
- 이 저장소의 `docs/ROADMAP.md`는 길다(약 700줄). 필요한 절만 읽는다: 1.3절(LLM, 시험 결과), 1.8절(라이선스 등급·읽기 양식), 4절(단계), 8절(결정).

## 8. 환경

- edgexpert: ARM(Cortex-X925/A725) + NVIDIA GB10, RAM 121GB, Ollama 0.32.14, 모델 `gemma4-e4b-24k`(gemma4:e4b + num_ctx 24576). qwen 서버는 내림. Ollama 기본 컨텍스트(4096)는 입력을 조용히 자르므로 24576 이상 필요.
- 도구: pdftotext, pdftoppm, tesseract, python3(표준 라이브러리만으로 시험 스크립트 동작).
- 이 클라우드 세션의 외부 접근: Crossref, PubMed/NCBI E-utilities, PMC Open Data(S3)는 접근됨. Europe PMC 렌더 PDF와 PMC 웹 PDF는 막힘.
